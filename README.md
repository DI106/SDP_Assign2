# SDP_Assign2
Clean Code Principles:

1) Meaningful Names – clear names such as Weapon, Armor, createWeapon(), and createArmor()
2) Small Methods – each method performs only one specific task
3) Focused Classes – each class has one clear responsibility
4) Avoid Duplication – object creation logic is separated into factories
5) Programming to Interfaces - the client uses Weapon, Armor, and EquipmentFactory instead of concrete classes
